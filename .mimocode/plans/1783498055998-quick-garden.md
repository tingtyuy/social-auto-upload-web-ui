# Plan: 账号管理 - 获取抖音最新作品分享链接

## 需求
在账号管理页面，每个账号自动同步最新作品的分享链接和链接中的 URL。先只做抖音。

## 实现方案

### 1. 数据库：给 user_info 表加字段
- **文件**: `backend/init_db.py`
- 在 `init_database()` 的 CREATE TABLE 中加 `latest_work_url TEXT DEFAULT ''`
- 在 `migrate_database()` 中加 ALTER TABLE 迁移（兼容旧数据库）

### 2. 抖音 sync_profile：抓取最新作品链接
- **文件**: `backend/impl/douyin/platform.py`
- 在 `sync_profile()` 方法中，打开创作者中心后，抓取最新作品的分享链接
- 返回 `(name, avatar, latest_work_url)` 三元组
- 抓取逻辑：导航到 `https://creator.douyin.com/creator-micro/content/manage` → 找到第一个作品 → 获取分享链接

### 3. 后端接口：保存最新作品链接
- **文件**: `backend/app.py` (syncProfile 接口，第 558-581 行)
- 解包返回的三元组 `(name, avatar, latest_work_url)`
- UPDATE 语句加 `latest_work_url` 字段
- 响应 JSON 加 `latest_work_url`

### 4. 前端：显示最新作品链接
- **文件**: `frontend/src/views/AccountManagement.vue`
- 在账号卡片中加一个"最新作品"链接按钮
- 点击打开分享链接

## 修改文件清单
1. `backend/init_db.py` — 加字段 + 迁移
2. `backend/impl/douyin/platform.py` — sync_profile 抓取最新作品链接
3. `backend/app.py` — syncProfile 接口处理新字段
4. `frontend/src/views/AccountManagement.vue` — 显示链接

## 验证
1. 在账号管理页面点击抖音账号的"同步"按钮
2. 同步完成后，账号卡片显示最新作品链接
3. 点击链接能打开抖音作品页面
